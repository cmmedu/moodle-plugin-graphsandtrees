Editor de grafos

Construye un grafo y exporta su JSON para el script de montaje del curso.

Instrucciones del editor

Nodos

  • Haz clic en un nodo para abrir su menú: texto, color, forma, agregar un nodo conectado, marcar el texto como blanco de respuesta, o eliminarlo.
  • Arrastra un nodo para moverlo (en "Modo árbol" la posición se recalcula automáticamente).

Conexiones

  • Al agregar un nodo conectado se crea automáticamente la conexión entre ambos.
  • Haz clic en una conexión para editar su etiqueta o eliminarla.

Modo grafo vs. modo árbol

  • Modo grafo: los nodos se ubican libremente, sin una jerarquía definida.
  • Modo árbol: los nodos se organizan automáticamente en niveles (padre/hijo), con orientación vertical u horizontal.
  • El estilo de línea (recta / en ángulo recto) y el zoom se controlan desde la barra superior del editor.

Edición de nodos y Conectores

Cambio de forma

  • Cada nodo puede tener una forma diferente

nodos como pregunta: "Marcar como input" / "Marcar como selector"

  • Marcar como input convierte el texto de un nodo o conexión en {{T_INPUT}}: el alumno verá una caja de texto para completar.
  • Marcar como selector lo convierte en [[opción1;opción2]]: el alumno verá una lista desplegable con esas opciones.
  • Puedes escribir texto antes y/o después de los corchetes en el mismo campo (por ejemplo antes [[Sí;No]] después) - ese texto se muestra igual, solo el contenido entre corchetes/llaves se convierte en el espacio en blanco.
  • Este editor solo genera el grafo por defecto (lo que ve el alumno). Las respuestas correctas para cada espacio en blanco se configuran aparte, en el grafo de respuesta dentro de Moodle.

Etiquetas flotantes (solo en modo árbol)

  • Un nodo sin hijos (una rama final) puede tener además una "+ Etiqueta flotante": un texto aparte que se muestra debajo del nodo (orientación vertical) o a su derecha (orientación horizontal) - útil, por ejemplo, para mostrar un porcentaje al final de una rama.
  • Haz clic en la etiqueta ya creada para editar su texto, marcarla como input/selector, o eliminarla.
  • Si el nodo deja de ser una rama final (se le conecta un hijo), la etiqueta se oculta pero su contenido no se pierde - reaparece si vuelve a quedar sin hijos.

grafo de repsuesta

  • luego de añadir los diferentes tipos de inputs a los grafos, se crea otro grafo mas que es el grafo de respuesta este conciste en el mismo grafo que el anterior pero con las respuestas esperadas, este tipo de preguntas acepta mas de uno como respuesta correcta.

Exportar el grafo

  • El botón "JSON" (en la barra superior del editor) abre un panel para copiar/pegar el JSON del grafo directamente.
  • Más abajo en esta página, "Copiar al portapapeles" y "Guardar como .json" hacen lo mismo con el grafo completo, listo para el script de montaje del curso.
  • "Descargar captura (PNG)" y "Descargar SVG" generan una imagen del grafo tal como se ve (todo el grafo completo, no solo lo visible en pantalla) - el PNG es un mapa de píxeles, el SVG queda editable en un programa de diseño vectorial.

Qué queda para el montaje en la plataforma

  • Los nombres de los niveles del árbol ("Nivel 0", "Nivel 1", ...) no se pueden cambiar en este editor. Basta con indicar en el guión de la clase cómo quieres que se llame cada nivel - quien haga el montaje los renombrará directamente en Moodle.
  • Este editor solo construye el grafo de entrada (el grafo por defecto que ve el alumno). El grafo de repsuesta (con las respuestas correctas, usado para la calificación automática) se arma aparte, dentro de Moodle. Indica en el guión de la clase cómo debe quedar tanto el grafo de entrada como el grafo de revisión.

"Marcar como input"/"Marcar como selector" convierten el texto en un espacio en blanco ({{T_INPUT}} o [[opción1;opción2]]) para el alumno - puedes escribir texto antes/después de los corchetes en el mismo campo. En "Modo árbol", un nodo sin hijos ofrece además "+ Etiqueta flotante": una etiqueta aparte (texto, input o selector) que se muestra debajo del nodo (vertical) o a su derecha (horizontal) - haz clic en la etiqueta ya creada para editarla o eliminarla.
